# PropIQ AI Pilot Test Accounts

## Safety Rule

Do not include real passwords in demo documents.

Use the seeded test password from the local ignored `.env.local` file. Do not
share this password in demo documents.

Do not include Supabase keys, database URLs, service-role keys, webhook
secrets, or any other credential in this file.

## Account Labels

| Role | Demo Account Label | Demo Use |
| --- | --- | --- |
| Owner | Seeded Owner demo account | Owner dashboard, Pilot KPI report, health status, integration readiness, and pilot-level review. |
| Admin | Seeded Admin demo account | Stage 3 manual intake, lead creation, setup-oriented review, and operational configuration discussion. |
| Manager | Seeded Manager demo account | Team workload, escalations, SLA breach visibility, duplicate review, and operational queues. |
| Executive | Seeded Executive demo account | Assigned leads, HOT actions, follow-up tasks, visits, SLA countdowns, and next best actions. |

## Demo Handling

- Keep credentials in ignored local environment files only.
- Do not paste passwords into chat, documents, tickets, screenshots, or slide
  notes.
- Rotate or reset seeded demo credentials before sharing access outside the
  local pilot-demo environment.
- Use fabricated test data only.
