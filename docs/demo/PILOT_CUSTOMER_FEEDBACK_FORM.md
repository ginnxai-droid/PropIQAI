# PropIQ AI Pilot Customer Feedback Form

## Context

PropIQ AI is being reviewed as a pilot-demo-ready revenue recovery and lead
discipline platform. The goal is to understand whether the workflow, metrics,
and operating views are useful enough for a controlled pilot.

## Owner Feedback

1. Are these metrics useful for reviewing sales operating discipline?
2. Which dashboard number would you trust before rollout?
3. Which dashboard number would you not trust yet?
4. Which metric is missing for an owner-level pilot review?
5. Does the Pilot KPI Report help you decide whether the pilot is working?
6. What would you need before approving wider rollout?

## Sales Head Or Manager Feedback

1. Are the operational queues actionable?
2. Are SLA alerts too noisy, too late, or useful?
3. Does the workload view help you manage the team?
4. Which queue would your team use every day?
5. Which escalation should be changed before pilot?
6. Does duplicate review help reduce scattered follow-up?

## Executive Feedback

1. Is the next action clear on assigned leads?
2. Does Lead Detail give enough buyer context?
3. Are tasks easy to follow?
4. Are SLA countdowns useful or distracting?
5. Does the site-visit follow-up flow match your daily work?
6. What information do you need before calling or following up with a buyer?

## CRM/Admin Feedback

1. Is setup practical for a pilot team?
2. Which integration is needed first after pilot validation?
3. What data fields are missing from intake?
4. What existing CRM field must be mapped before live pilot use?
5. Is the `Not available` labeling clear enough for unsupported providers?
6. What controls are required before production deployment?

## Final Pilot Decision Questions

1. Should PropIQ AI proceed to a controlled pilot-demo with selected users?
2. What must be fixed before the pilot-demo?
3. What can remain deferred until after pilot validation?
4. Who should own pilot success measurement?
5. What date should be used for the next review checkpoint?
