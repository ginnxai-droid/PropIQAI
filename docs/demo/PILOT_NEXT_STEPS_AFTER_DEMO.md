# PropIQ AI Next Steps After Demo

## Immediate Demo Follow-Up

1. Collect feedback from owner, sales, CRM, marketing, operations, manager, and
   executive stakeholders.
2. Separate feedback into:
   - demo blockers;
   - pilot blockers;
   - post-pilot enhancements;
   - production-deployment requirements.
3. Confirm whether the current pilot-demo scope is accepted for stakeholder
   review.
4. Confirm which unavailable capability matters most for pilot planning.

## Pilot Planning

Before a controlled pilot, decide:

- pilot organization or project scope;
- number of users by role;
- lead sources to include;
- required intake fields;
- daily manager review cadence;
- SLA rules to use;
- dashboard review cadence;
- feedback owner;
- pilot start and end dates;
- success criteria and acceptance meeting date.

## Data And Access Handling

- Use test data for demos.
- Do not share seeded passwords in documents.
- Keep credentials in ignored local environment files.
- Do not expose Supabase keys, database URLs, service-role keys, webhook
  secrets, or buyer personal data.
- Before any live pilot, define who can access buyer data and how test data is
  separated from real data.

## Product Boundary

The product is accepted for pilot-demo preparation, not production deployment.
Stage 5 is not started.

Do not treat this demo pack as approval for:

- production deployment;
- live buyer-data rollout;
- paid external integrations;
- Stage 5 implementation;
- merge or push actions.
