# Stage 5B Demo Feedback Capture

Updated: June 17, 2026

## Instructions

Use this template after each pilot demo rehearsal or stakeholder demo. Capture
business feedback separately from production-readiness requests. Do not paste
passwords, secrets, real buyer data, production endpoints, or private customer
records into this document.

## Feedback Categories

Classify every item as one of:

- demo blocker;
- pilot blocker;
- post-pilot enhancement;
- production blocker;
- out-of-scope integration request;
- training or messaging issue.

## Owner / Developer Owner Questions

1. Are the dashboard metrics useful for a pilot review?
2. Which number would you trust before rollout?
3. Which number needs more explanation?
4. What would block a controlled pilot?
5. What would block production deployment?

## Sales Head / Manager Questions

1. Are the queues actionable?
2. Are SLA alerts useful or noisy?
3. Does workload visibility help daily management?
4. Which queue should be reviewed first each morning?
5. What escalation rule would need adjustment?

## Executive Questions

1. Is the next action clear?
2. Does Lead Detail provide enough buyer context?
3. Are follow-up tasks practical?
4. Is the SLA countdown useful?
5. What would make this easier to use during a real sales day?

## CRM / Admin Questions

1. Are intake fields sufficient for a pilot?
2. Which integration is actually required first?
3. Which field is missing for CRM continuity?
4. Is setup practical for demo or pilot operations?
5. What should remain deferred?

## Follow-Up Summary

After collecting feedback, summarize:

- top three must-fix items;
- top three nice-to-have items;
- any production blocker;
- any request that belongs outside Stage 5B;
- recommended next gate.
